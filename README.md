## 📌 Executive Summary

Modern CCTV surveillance systems from vendors such as Dahua, Hikvision, CP PLUS, and TVT utilize custom, undocumented raw disk layouts (e.g., DHFS, Hikvision proprietary sector structures) and proprietary container encapsulations (DHAV, Hikvision stream blocks). Standard forensic tools (Autopsy, FTK) or standard OS mount tools fail to parse these unallocated raw volumes or misidentify them as unformatted raw space.

This tool provides:
1. **Read-Only Raw Disk Image Acquisition & Verification**: Memory-mapped binary parsing (`mmap` `ACCESS_READ`) with dual SHA-256 and MD5 hash calculation. Rejects physical drive paths (`\\.\PhysicalDriveN`) to guarantee non-destructive operation.
2. **Brand Auto-Detection**: Fast sector-level magic byte scanning (DHAV for Dahua, `HIKVISION@HANGZHOU` master sector for Hikvision).
3. **Frame-Level Carving & Re-assembly**: Carves individual frames using 8-point header validation, groups frames into per-camera streams, detects recording gaps, and categorizes segments into `COMPLETE`, `PARTIAL`, or `UNCERTAIN`.
4. **Non-Destructive FFmpeg Remuxing**: Stream copy (`-c copy`) without re-encoding to retain original video bitstreams.
5. **Cryptographic Hash-Chained Audit Log**: Every operation is logged with an unbroken SHA-256 hash chain:  
   $$\text{Hash}_n = \text{SHA-256}(\text{Timestamp}_n \parallel \text{Action}_n \parallel \text{Params}_n \parallel \text{Hash}_{n-1})$$
6. **Court-Ready PDF Forensic Report**: Automated PDF generation featuring cover page, integrity hashes, segment breakdown, audit log dump, and a **Section 63(4) Bharatiya Sakshya Adhiniyam 2023** (formerly IEA 65B) electronic evidence certificate template.

```cmd

```

### Linux / macOS
```bash
# 1. Setup virtual environment & dependencies
chmod +x install.sh run.sh
./install.sh

# 2. Launch local server and open UI
./run.sh
```

## ⚖️ Legal & Compliance Context

This tool was designed in alignment with Indian legal standards for electronic evidence admissibility:
- **Bharatiya Sakshya Adhiniyam 2023 (BSA) Section 63(4)**: Replaces Indian Evidence Act 1872 Section 65B. Part A of the generated certificate is populated automatically with system parameters, software versions, and cryptographic hashes.
- **ISO/IEC 27037**: Guidelines for identification, collection, acquisition, and preservation of digital evidence.

## ⚠️ Known Limitations

1. **Synthetic Test Data**: All unit tests run against synthetically generated disk images. No accuracy or performance metrics have been measured on a real physical recorder.
2. **No Real-World Accuracy Claims**: Numbers derived from synthetic test runs MUST NOT be described or presented as real-world recovery rates or accuracy statistics.
3. **Index Reading Not Implemented**: Neither Dahua DHFS index parsing nor Hikvision HIKB-TREE index reading is implemented in v1. Recovery relies on frame carving until real-disk index structures are verified.
4. **Hikvision Carving is Experimental**: Hikvision NAL stream carving is marked experimental; carved Hikvision segments are labelled `UNCERTAIN` by default unless `ffprobe` decodes them cleanly.
