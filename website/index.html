Forensic Problem Statement

Why We Built It

CCTV and surveillance digital evidence present unique obstacles that defeat traditional commercial data recovery tools. SIH26150 was engineered specifically to solve the core challenges faced by forensic examiners.

01 / PROPRIETARY STORAGE

Non-Standard Filesystems

DVR and NVR manufacturers frequently bypass NTFS, FAT32, or ext filesystems. Media is written in vendor-specific structures (such as DHFS 4.1 or custom circular buffers) that Windows and standard OS tools fail to mount or recognize.

Impact: OS reports disk as raw / unformatted
02 / DELETED FOOTAGE

Hidden & Overwritten Sectors

When video is deleted or marked for circular overwrite, normal player menus cannot access it. Critical incident footage remains trapped inside unallocated clusters or orphaned video blocks across the storage volume.

Impact: Cannot be extracted via DVR UI
03 / STREAM FRAGMENTATION

Interleaved Multi-Camera Feeds

Surveillance recorders multiplex 4, 8, 16 or 32 cameras into interleaved sector streams. Generic file carvers yield scrambled, corrupted media files with out-of-order frames and mismatched camera channels.

Impact: Corrupted playback & lost timeline
04 / EVIDENCE INTEGRITY

Strict Write-Protection

Plugging a CCTV hard drive into a standard workstation can trigger automated disk signature writing or indexing changes. Forensic evidence must be handled in strictly enforced read-only modes with pre/post cryptographic hashes.

Impact: Contamination voids court admissibility
05 / SCIENTIFIC VALIDATION

Repeatable Verification

Carving alone does not guarantee stream integrity. Forensic examiners require frame-by-frame structural validation via ffprobe/FFmpeg to detect corrupt macroblocks, dropped GOP sequences, and decode failures.

Impact: Unvalidated carving creates false positives
06 / COURT TRACEABILITY

Immutable Chain of Custody

Every byte analyzed must be accountable. Analysis requires cryptographically linked audit trails, Section 65B (Indian Evidence Act) / BSA 2023 §63(4) electronic record certificates, and transparent confidence ratings.

Impact: Required for judicial proceedings
Execution Architecture

The Forensic Recovery Pipeline

A modular, scientific workflow designed to maintain strict evidentiary hygiene from raw disk image acquisition through final court-ready reporting.

STAGE 01
01 — ACQUIRE & PRE-HASH
Read-Only Enforced

Mounts raw forensic images (.dd, .raw, .img, .bin) using kernel read-only memory mapping (mmap ACCESS_READ). Computes initial baseline SHA-256 and MD5 cryptographic hashes before any scanning takes place.

mmap ACCESS_READ SHA-256 Baseline MD5 Baseline Raw LBA Addressing
STAGE 02
02 — IDENTIFY & PROFILE
Plugin Registry

Executes signature profiling across master boot records, partition sectors, and raw stream headers. Identifies brand signatures (Dahua DHFS/DHAV, Hikvision HIK, CP Plus) or routes automatically to generic standards-based carving.

BrandPlugin Registry DHAV Magic 0x44484156 HIK Signatures Fallback Router
STAGE 03
03 — INDEX & ALLOCATION PARSE
Metadata Recovery

Parses available vendor filesystem tables, chunk allocation descriptors, and channel mapping indexes. Pinpoints active, deleted, and unallocated cluster ranges for targeted extraction.

DHFS 4.1 Index Parser Cluster Descriptors Channel Allocation Maps
STAGE 04
04 — DEEP SECTOR CARVE
Unallocated Space Scan

Sweeps unallocated disk space for frame boundaries, NAL unit starts (H.264 0x0000000167, H.265 0x0000000140), MPEG-PS pack headers (0x000001BA), and proprietary trailer tags with sector alignment.

H.264 Annex B Carver MPEG-PS Pack Carver dhav Trailer Detection Byte-Level Boundary Scan
STAGE 05
05 — STREAM RECONSTRUCTION
De-interleaving & GOP Alignment

Demultiplexes interleaved multi-channel feeds. Groups frames by camera channel ID, sorts sequential presentation timestamps (PTS), recovers Group of Pictures (GOP) headers, and synthesizes standard MP4 containers.

reconstructor.py Multi-Channel Demux GOP Re-alignment Container Remux
STAGE 06
06 — FORENSIC VALIDATION
FFmpeg / ffprobe Probe

Validates carved media with FFmpeg and ffprobe. Detects corrupt macroblocks, dropped frames, audio/video synchronization deltas, and assigns scientifically honest confidence states (Complete / Partial / Uncertain).

ffprobe Stream Analysis Macroblock Validation Frame Drop Counter Confidence Engine
STAGE 07
07 — AUDIT CHAIN & REPORTING
Court-Admissible Output

Verifies post-scan evidence hash match. Appends timestamped examiner actions to an immutable hash-chained audit log. Generates forensic PDF reports and Bharatiya Sakshya Adhiniyam 2023 §63(4) / Section 65B certificates.

Post-Scan Hash Verification Hash-Chained Audit Trail BSA 2023 §63(4) Certificate Forensic PDF Report

Evidentiary Standard

Forensic Confidence States

A video file carved from raw disk sectors cannot automatically be declared “intact” simply because bytes were written. Our engine classifies every reconstructed file into verified, defensible confidence levels.

COMPLETE VERIFIED INTEGRITY

Both container and internal Elementary Stream decoded cleanly with zero syntax errors, intact sequence parameter sets (SPS/PPS), continuous timestamps, and verified closed GOP boundaries. Only assigned against verified ground truth.

PARTIAL CARVED WITH GAPS

Reconstructed footage contains playable sequences with detected dropped frames, missing GOP headers, or minor macroblock artifacts. Clearly flagged for examiner review.

UNCERTAIN RAW FRAGMENTS

Raw video slices extracted without definitive container timing, interleaved channel confirmation, or corrupt stream markers. Requires manual examiner analysis in the player viewport.

Core Capabilities

Engineered for Real DFIR Labs

A complete forensic workstation suite with no external cloud dependencies, built specifically for digital forensics investigators and incident responders.

Read-Only Disk Acquisition

Mount raw disk images (.dd, .raw, .img, .bin) and physical drives in strictly enforced read-only memory mappings (mmap ACCESS_READ). Prevents OS write contaminations.

Instantly identifies Dahua, Hikvision, CP Plus, and Honeywell filesystem headers or falls back gracefully to standards-based carving.

AI Analytics: Face & Object Search

Court-Admissible PDF & BSA §63(4)

Security Hardened

Zero Cloud Leaks. Local-First Architecture.

Surveillance evidence contains sensitive footage and legal investigations that must never cross public networks or third-party cloud infrastructure.

  • 100% Localhost & Air-Gapped

    Operates completely disconnected from the Internet. Zero analytics beacons, zero telemetry, zero external dependencies during scanning.

  • Named Examiner Role-Based Accounts

    Enforces examiner accountability with salted Argon2id / secure password hashing, session expiration, and lockout policies.

  • Strict Path Traversal Sandboxing

    Backend endpoints strictly sanitize file paths, preventing directory traversal attacks (../) and unauthorized disk tampering.

  • Cryptographic Tamper Detection

    Source evidence hashes are recorded before scanning and verified after processing to guarantee byte-for-byte evidence preservation.

Windows Installation & First Launch

Follow these steps to deploy the SIH26150 Forensic Analysis Tool to your Windows digital forensics lab workstation.

STEP 01

Download & Unblock

Click Download for Windows to get SIH-Forensic-Tool-Setup.exe. If Windows blocks opening due to security settings: Right-click the .exe → Properties → check Unblock → Apply, or on SmartScreen click More info → Run anyway.

STEP 02

Windows Setup Wizard

Run the installer. Accept the licensing terms, select your target installation folder (default: C:\Program Files\SIH Forensic Tool), and click Install.

STEP 03

Launch Application

Launch the application from the Start Menu or desktop shortcut. The tool initializes the local runtime and presents the welcome screen.

STEP 04

Create Examiner Account

Configure your initial examiner administrator account with a secure password.

Password Requirements:

About SIH26150

The SIH26150 Multi-Vendor DVR/NVR Forensic Analysis Tool was developed as part of the Smart India Hackathon 2026 under Problem Statement ID SIH26150.

Our mission was to build a rigorous, open, and legally defensible digital forensics platform capable of recovering surveillance video evidence from proprietary CCTV hardware. By adhering strictly to ISO/IEC 27037 digital evidence preservation standards and Bharatiya Sakshya Adhiniyam 2023 §63(4) statutory certificate requirements, this software provides law enforcement officers and DFIR laboratories with a dependable, transparent recovery platform.
